# codestory v0.1.0 — turn any codebase into an animated book of workflows

codestory takes a real repository and produces a single self-contained HTML file: a paged, animated book where each page is a workflow — an HTTP request, a Celery task, a queue consumer, a scheduled job. One file you can open offline, drop into a wiki, or commit next to the code.

The visual format is a sequence-diagram-style story per flow: actors on the left, time flowing down, side-effects (DB writes, external HTTP calls, queue pushes, websocket pushes) called out where they happen. Four themes ship in the box: `cococream` (warm, paper-like), `dark` (terminal green-on-black), `minimal` (no chrome), and `nothing-design` (Nothing brand language). Pick one with `/codestory theme <name>`.

The discovery model is the rule that keeps it honest: every step in every flow cites `file:line` from the source repo. When the discovery script cannot resolve a step — a dynamic dispatch, a string-built SQL, an absent type — the step is marked `unknown`, not invented. The rendered HTML preserves that mark. Read more in [../DISCOVERY.md](../DISCOVERY.md).

## What's in v0.1.0

**Examples** (each shipped with `flows.json` and rendered HTML across all four themes):

- [medchat](../../examples/medchat/) — the gold-standard medical-chat flow visualisation that seeded this project
- [fastapi-starter](../../examples/fastapi-starter/) — minimal FastAPI app with one route and one background task
- [nextjs-starter](../../examples/nextjs-starter/) — minimal Next.js app with one API route and one server action
- [django-celery](../../examples/django-celery/) — Django view, Celery task, and a scheduled beat job

**Themes:**

- `cococream` — warm, paper-like, designed for reading
- `dark` — green-on-black, designed for terminals
- `minimal` — no chrome, designed to embed
- `nothing-design` — Nothing brand language, designed to print

## How discovery works

codestory parses entry points (HTTP routes, queue consumers, schedulers, CLI commands), walks each one statically, and records every side-effect with a `file:line` citation. Unresolved branches are marked `unknown` and rendered with a question mark; they are never silently dropped or guessed at. Full discovery rules and detector list are in [../DISCOVERY.md](../DISCOVERY.md).

## Installation

In Claude Code, add the marketplace, then install the plugin:

```
/plugin marketplace add phj6688/codestory
/plugin install codestory@codestory
```

Then in any repo:

```
/codestory
```

A `codestory.html` is written to the repo root. Open it in any browser.
